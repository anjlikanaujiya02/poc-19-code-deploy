# POC-19 – CI/CD Branching Using GitHub Actions

## Objective
Demonstrate CI/CD workflow using GitHub Actions with feature branching.

## Workflow
1. Developer creates a feature branch.
2. CI pipeline runs automatically on feature branch.
3. Pull request is created and reviewed.
4. After merge to main, CD pipeline runs.

## Tools Used
- GitHub
- GitHub Actions
- Node.js
- Jest

## Outcome
Automated CI/CD flow successfully implemented.
